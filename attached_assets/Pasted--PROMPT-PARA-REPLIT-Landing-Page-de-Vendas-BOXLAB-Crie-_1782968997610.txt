# PROMPT PARA REPLIT — Landing Page de Vendas "BOXLAB"

Crie uma landing page de vendas **completa, funcional e responsiva** em HTML, CSS e JavaScript puro (ou React, se for o padrão do seu template Replit), para venda do infoproduto **BOXLAB — 150 Dinâmicas para Aulas de Boxe**.

## Stack e requisitos técnicos
- HTML5 semântico + CSS3 (Flexbox/Grid) + JavaScript vanilla (sem dependências pesadas). Se o projeto Replit já for React/Vite, use componentes funcionais com hooks.
- Totalmente **responsiva** (mobile-first): breakpoints em 480px, 768px e 1024px.
- Performance: imagens otimizadas/lazy-loaded, CSS e JS organizados em arquivos separados (`styles.css`, `script.js`).
- Meta tags de SEO (title, description, Open Graph) e favicon.
- Sem frameworks de pagamento reais — os botões de compra devem apontar para `#` ou para uma variável `CHECKOUT_URL` configurável no topo do JS, fácil de trocar depois.
- Acessibilidade básica: contraste adequado, `alt` em imagens, navegação por teclado nos botões e no acordeão de FAQ.

## Identidade visual
- Paleta: **preto (#0a0a0a) predominante, vermelho vibrante (#e10600), branco (#ffffff) e dourado (#d4af37)** — dourado reservado para destacar o plano Premium.
- Tipografia: fonte de impacto para títulos (ex: Bebas Neue, Anton ou Oswald via Google Fonts) + fonte legível para corpo de texto (ex: Inter ou Roboto).
- Elementos visuais: ícones esportivos (lucide-react ou SVGs inline — 🥊🏆📩🛡), sombras, leve efeito metálico no dourado, botões com hover/transição suave, cards com bordas arredondadas e leve elevação.
- Imagens: usar placeholders de alta qualidade relacionados a boxe (ex: Unsplash — luvas, saco de pancada, atletas treinando). Deixe comentado no código onde trocar por imagens reais do cliente.
